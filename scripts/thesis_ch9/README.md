# Thesis results chapter (Ch. 8 in the current build; Hodgkin-Huxley only) — simulations and figures

Current thesis figures: `fig9_1_protocol`, `fig9_2_maps`, `fig9_3_nonlinearity`, `fig9_4_variability` (`make_figures.py protocol maps nonlinearity variability`). The Izhikevich, network and model-free scripts (E3, E5, E6, parts of E2/E4) are kept for reference but are no longer used in the thesis.

Python (numpy, numba, scikit-learn, matplotlib with LaTeX) reimplementation of the
Chapter 7/5 models used for Chapter 9, "Trial-by-trial variability in the response of
spiking neural networks to stimulation". Run all scripts from this folder; outputs
go to `out/`, figures to `figs/` (copy them to `tese/figures/ch9/`).
Runtimes are wall-clock on 2 cores.

## Modules
| file | content |
|---|---|
| `ch9_models.py` | numba RK4 integrators: HH chain (V,m,h,n,s) and Izhikevich chain (v,u,s) with event-accurate reset (bisection on the whole-system substep); OU noise; route-D propagated signal |
| `ch9_circuits.py` | `Circuit`, `chain()`: Chapter 7 motifs (gap/chem links, V_th = presynaptic rest), equilibria, tau_0 |
| `ch9_protocol.py` | pump–probe with common random numbers, central difference G = [V(+q) − V(−q)]/2q |
| `ch9_analysis.py` | L2 norms, telescoping node/link factors, covariance shares, spike-time sensitivities |
| `ch9_network.py` | Chapter 5 network (all-to-all mean-field coupling), event-accurate resets, burst onsets, Kuramoto R, branching integrator with filtered mean field z |

## Notes
- Seeds are fixed in every script; results are reproducible up to floating-point
  differences between numba builds.
- The rho(S) values are cross-validated R^2 of HistGradientBoosting regressions with
  folds grouped by onset state (motifs) or 5-s blocks (network); they are lower bounds.
- Network runs are single realizations (N=120 seed 3; N=40 seed 2). N=60 seed 1 did not
  show intermittency within 1000 s and was not used.
